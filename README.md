# ⚡ Cyber Linux CTF Platform & Telegram Bot

A full-fledged Linux Security & DevOps training platform with 50 Hard-Level CTF challenges, 1-to-1 dynamic ephemeral SSH instance spawner, and Telegram Bot AI integration.

## 🚀 Features
* 50 Hard-Level Linux CTFs (Memory Forensics, SUID, Capabilities, Covert Sockets, AWK Forensics, Systemd Persistence).
* 1-to-1 Ephemeral Sandbox SSH instances with auto-destroy.
* Integrated Telegram Bot (@fara_ai_vision_bot).
* 24/7 Docker Container ready.

## 🛠️ Quick Start
```bash
docker compose up -d
```
